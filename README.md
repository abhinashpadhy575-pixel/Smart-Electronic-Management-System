# Smart Electronic Product Management System

## 📌 Project Overview

The **Smart Electronic Product Management System** is a C++ based Object-Oriented Programming (OOP) project designed to manage and organize electronic products efficiently.

The system provides a structured way to store product information and perform different management operations. It demonstrates the practical implementation of important OOP concepts in a real-world management system.

## 🎯 Objectives

- Manage electronic product information efficiently.
- Add and maintain product records.
- Display product details.
- Perform product management operations.
- Demonstrate Object-Oriented Programming concepts.
- Build a simple and user-friendly console-based management system.

## 🛠️ Technologies Used

- **Language:** C++
- **Programming Paradigm:** Object-Oriented Programming
- **Compiler:** GCC / MinGW
- **Interface:** Console-based

## 🧠 OOP Concepts Used

This project demonstrates several important concepts of Object-Oriented Programming:

- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Constructors
- Member Functions
- Access Specifiers
- Function Overloading

## ⚙️ Main Features

- Electronic product management
- Product information handling
- Product details display
- Product operations through a menu-driven interface
- Structured data management using classes
- Simple console-based interaction
